# VAD-OS Spark Monitor

Переносимый терминальный монитор Spark-машин, серверов моделей и статистики
ключей LiteLLM. Работает только пока запущен; по выходу закрывает свои SSH-туннели.

В программе **не записаны адреса кластера**. Она сама находит машины в вашем
tailnet через локальный клиент Tailscale и определяет запущенные серверы моделей.

## Требования

- Linux или macOS. На Windows используйте WSL.
- Tailscale, выполненный вход и доступ к тому же tailnet, где находятся Spark.
- SSH-доступ к Spark; по умолчанию пользователь `nvidia`.
- Python 3.10+ с модулем `curses` — только для Linux-варианта `.pyz`.
- Ключ LiteLLM с доступом к статистике.

Проверка Python на Linux/macOS:

```bash
python3 -c "import curses; print('OK')"
```

## Установка и запуск

1. Сохраните `spark-monitor.pyz` в любую папку и откройте в ней терминал.
2. Один раз сохраните свой ключ LiteLLM (ввод скрытый):

   ```bash
   python3 spark-monitor.pyz --save-key
   ```

3. Запустите монитор:

   ```bash
   python3 spark-monitor.pyz
   ```

Внутри нажмите `l` для статистики LiteLLM. Флаги запуска не обязательны.

Ключ хранится в `.env` рядом с программой. **Не передавайте этот файл другим.**

## Mac с Apple Silicon (включая M5)

Python устанавливать не нужно. Распакуйте архив из `macos/` целиком и откройте
`Start Spark Monitor.command`. При первом запуске будет запрошен ключ.
Подробности — в `README-Mac.md` внутри архива.

## Автообнаружение

Монитор читает список машин из `tailscale status` и выбирает включённые Linux-машины,
имена которых подходят под шаблон `spark-*`. Для каждой найденной машины он:

- показывает GPU/RAM;
- ищет серверы vLLM/gb10 и embedding-модели, включая модели в контейнерах;
- создаёт SSH-туннель только к найденному HTTP-порту и обновляет карточку.

LiteLLM определяется по адресу порта `4000` на одной из Spark-машин.
Новые контейнеры появляются автоматически в течение 30 секунд; остановленные
помечаются, а не исчезают молча.

Если ваши машины называются иначе:

```bash
python3 spark-monitor.pyz --spark-pattern 'gpu-node'
```

Если автоматический поиск не подходит, можно задать адреса вручную:

```bash
python3 spark-monitor.pyz --no-discovery --host SERVER_IP --remote-port 8000
```

Ручной режим требует явных адресов и не подходит для обычной работы.

## Обновления

При запуске монитор проверяет GitHub Releases. Если вышла новая версия, он
скачивает `spark-monitor.pyz`, проверяет SHA-256 и заменяет файл, сохраняя
резервную копию `.prev`. Ключ и `.env` не затрагиваются. Для применения
обновления перезапустите монитор.

```bash
python3 spark-monitor.pyz --check-update   # проверить и обновить сейчас
python3 spark-monitor.pyz --no-update-check
python3 spark-monitor.pyz --version
```

Автообновление работает только при запуске файла `.pyz`. Сборка macOS обновляет
встроенный `.pyz`; встроенный Python не заменяется.

## Права LiteLLM

LiteLLM автоматически показывает все доступные ключи администратору или только
текущий ключ обычному пользователю. Ключу должно быть разрешено чтение статистики;
ключи только для вызовов моделей (`llm_api_routes`) этого доступа не дают.

Если появляется 403, администратору нужно сохранить в **Virtual Keys → Edit →
Allowed Routes**:

```text
llm_api_routes, /user/info, /key/info, /user/daily/activity/aggregated
```

Повышать роль пользователя до администратора для личной статистики не нужно.

## Короткая команда (необязательно)

В Bash/Zsh, находясь в папке с `.pyz`:

```bash
python3 - <<'PY'
from pathlib import Path
import shlex
p = Path('spark-monitor.pyz').resolve(strict=True)
f = Path.home() / '.local/bin/spark-monitor'
f.parent.mkdir(parents=True, exist_ok=True)
with f.open('x') as s:
    s.write('#!/bin/sh\nexec python3 ' + shlex.quote(str(p)) + ' "$@"\n')
f.chmod(0o755)
PY
export PATH="$HOME/.local/bin:$PATH"
```

Теперь запуск: `spark-monitor`. Если `~/.local/bin` не был в `PATH`, добавьте
строку `export` выше в `~/.bashrc` или `~/.zshrc`.

Удалить короткую команду (монитор и ключ останутся):

```bash
rm -- "$HOME/.local/bin/spark-monitor"
```

## Управление

| Клавиша | Действие |
|---|---|
| `l` | Статистика LiteLLM / модели |
| `Tab` | Обычные / embedding-модели |
| `h` | Показать / скрыть пояснения |
| `-` | Обновлять реже |
| `=` / `+` | Обновлять чаще |
| `1`–`4` в LiteLLM | 1 день, 7 дней, 30 дней, год |
| Стрелки / PgUp / PgDn | Прокрутка |
| `q` / Ctrl+C | Выход |

GPU/RAM опрашиваются не чаще раза в 5 секунд, LiteLLM — раз в минуту.
Периоды LiteLLM — календарные дни UTC, не скользящие 24 часа.
Ключи `key-hash…` и безымянные ключи исключены из таблицы и итогов.
